# Vecta — AI Application Assistant

Browser extension that auto-fills job applications, syncs your session activity, and tracks your job search progress across ATS platforms (Greenhouse, Lever, LinkedIn, Workday, Glassdoor, Indeed, and more).

## Install (manual, from Releases)

1. Go to the [**Releases**](../../releases) page.
2. Download the latest `vecta-extension.zip` from the release assets.
3. Unzip the file.
4. Open `chrome://extensions/` in Chrome (or any Chromium-based browser — Edge, Brave, Arc, etc.).
5. Enable **Developer mode** (toggle in the top right).
6. Click **Load unpacked** and select the unzipped `dist` folder.
7. Pin **Vecta** to your toolbar.

That's it. The extension will appear in your toolbar and activate on supported job boards.

## Updates

This is a side-loaded build, so Chrome will not auto-update it. To get a new version:

1. Re-download the latest `vecta-extension.zip` from Releases.
2. Remove the old extension from `chrome://extensions/`.
3. Load the new `dist` folder via **Load unpacked** (steps 5–6 above).

## Supported sites

Greenhouse, Lever, LinkedIn, Workday, Glassdoor, Indeed, Workable, Dice, ZipRecruiter, Bayt, Wellfound, Seek, Reed, BuiltIn. The extension activates only on these domains.
